## 🛡️ منظومة الأمان والخصوصية بنسبة 300% (300% Security & Anti-Piracy Suite)

تم تحصين الموقع بنظام حماية متعدد الطبقات بمستوى **300%** لضمان أقصى درجات الأمان والخصوصية لصاحب الموقع وللعملاء، مع حفظ حقوق الملكية الفكرية الدولية:

### 1. درع منع السرقة وسحب الوسائط (Media Anti-Theft Shield)
- [x] **تعطيل النقر الأيمن الذكي**: حظر قائمة النقر الأيمن المخصصة على الصور، الفيديوهات، الكانفاس، البطاقات، والنوافذ المنبثقة مع إظهار إشعار Toast أنيق يوضح أن كافة المواد محمية بحقوق النشر.
- [x] **منع السحب والإفلات (Anti-Drag)**: تطبيق `user-drag: none; -webkit-user-drag: none;` ومنع أحداث `dragstart` نهائياً على كافة وسائط الموقع.
- [x] **عزل التحديد والنسخ العشوائي**: تطبيق `user-select: none` على أجزاء الواجهة الحساسة وإطارات المشاريع.

### 2. درع حظر أدوات الفحص والتطفل (Source Inspection & Debugging Shield)
- [x] **حظر مفاتيح المطورين (Windows & Mac)**: منع اختصارات كشف السورس كود وتنزيل الملفات:
  - `F12`
  - `Ctrl + Shift + I` / `Ctrl + Shift + J` / `Ctrl + Shift + C`
  - `Cmd + Alt + I` / `Cmd + Alt + J` / `Cmd + Alt + C` (Apple macOS)
  - `Ctrl + U` / `Cmd + U` (View Page Source)
  - `Ctrl + S` / `Cmd + S` (Save Page HTML)
  - `Ctrl + P` / `Cmd + P` (Print Screen Dialog)
- [x] **حماية الإطارات (Anti-Clickjacking)**: فرض `X-Frame-Options: SAMEORIGIN` و CSP `frame-ancestors 'self'` لمنع تضمين الموقع في أي صفحات خارجية مشبوهة.

### 3. حماية البريد وأرقام التواصل ضد زواحف السبام (Anti-Scraping Harvesters)
- [x] **التجميع الديناميكي في الذاكرة**: تشفير وتفكيك البريد الإلكتروني ورقم الواتساب إلى أجزاء مجزأة يتم تركيبها عبر الجافاسكريبت حصراً في الـ DOM عند تفاعل المستخدم الحقيقي، مما يمنع عناكب الجمع الآلي من استخراجها في الكود الثابت.
- [x] **حقول التمويه الذكية (Honeypot Protection)**: إدراج حقول خفية في نماذج المراسلة والتقييم تسقط أي روبوت سبام آلي يحاول ملء النموذج فورياً وبدون إزعاج.

### 4. سياسة أمان المحتوى الصارمة وحماية الخادم (Strict CSP & Server Isolation)
- [x] **سياسة أمان المحتوى (CSP)**: تقييد مصادر النصوص، الصور، الفيديوهات، والخطوط بدقة بالغة.
- [x] **حماية الروابط المنبثقة**: تعقيم كافة الروابط الخارجية بـ `target="_blank" rel="noopener noreferrer"`.
- [x] **أمان لوحة التحكم (CSRF & Origin Isolation)**: رفض أي طلب POST لا يأتي من مضيف محلي مصرح به، مع تقييد معدل الطلبات (Rate Limiting: 60 طلب/دقيقة لكل IP).
- [x] **التحقق من البايتات السحرية للصور (Magic Bytes Check)**: فحص التوقيع الثنائي الفعلي للملفات المرفوعة للتأكد من أنها صور حقيقية (PNG, JPG, WebP, SVG) ومنع رفع أي برمجيات خبيثة.

### 5. حماية الملكية الفكرية والتوثيق الرقمي (DMCA & IP Protection)
- [x] **بصمة رقمية في الكونسول**: توثيق حقوق الطبع والنشر لعام 2026 في بيئة التشغيل.
- [x] **شارة الحماية في الفوتر**: شارة قانونية معتمدة توضح حماية الوسائط والأكواد وفق معايير الحماية الدولية للملكية الفكرية.

## ⚡ معمارية تسريع كرت الشاشة بنسبة 100% (GPU Acceleration Engine)

حرصاً على تقديم أداء فائق وتجربة بصرية سينمائية بدون استهلاك المعالج المركزي (CPU)، تم تزويد الموقع بمحرك تسريع عتادي:
- **عزل طبقات الكومبوزيتور**: تطبيق `contain: strict;` و `transform: translate3d(0, 0, 0);` على كانفاس الجزيئات (`#gpu-particles`) لمنع حدوث أي (Layout Reflows).
- **إلغاء التظليل البرمجي الثقيل (Zero CPU ShadowBlur)**: استبدال دوال `ctx.shadowBlur` بفلاتر عتادية مسرعة على الـ GPU Shaders.
- **الحساب التربيعي للمسافات**: خوارزمية ذكية تتفادى ملايين عمليات `Math.sqrt()` داخل حلقة الفحص لحفظ طاقة المعالج.
- **مؤشر نيون مسرع بالعتاد**: حركة المؤشر المضيء مبنية حصراً على `translate3d(x, y, 0)` و `scale()` لضمان معدل **120 FPS** ثابت ومستقر.
- **وضع السكون التلقائي**: توقف محركات الأنيميشن بالكامل فور تصغير النافذة أو مغادرة التبويب، مما يخفض استهلاك الـ CPU إلى **0.0%**.

## ⚙️ سير العمل والمزامنة التلقائية | Build & Sync Pipeline

أنقر نقراً مزدوجاً على ملف:
```text
Run_Studio.bat
```
أو عبر موجه الأوامر:
```bash
python admin_server.py
```
ثم افتح الرابط: `http://localhost:4321/admin/index.html`

### 2. التجميع التلقائي لكافة المسارات:
عند تعديل أي محتوى أو بيانات في الموقع، يقوم سكربت البناء المركزي بتحديث كافة النسخ المتطابقة تلقائياً:
```bash
python compiler.py
```

### 3. النشر والمزامنة السحابية بنقرة واحدة:
أنقر نقراً مزدوجاً على ملف:
